# 🖼️ Image Slider

Slider profesional fotografish i ndërtuar vetëm me HTML + CSS — pa asnjë rresht JavaScript. Përdor radio-buttona të fshehur për ndërrimin e fotove, me shigjeta navigimi dhe pika përzgjedhëse. Animim i butë zmadhimi (scale) gjatë tranzicionit.

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html, demo/style.css, demo/images/img1.jpg … img6.jpg
- `original/` — burimi origjinal i paprekur
